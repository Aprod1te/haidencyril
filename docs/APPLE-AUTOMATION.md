# 苹果自动化

## 随手捕捉快捷指令

插件注册了 `obsidian://haidencyril-capture`。推荐建立一个名为“记录到 Haidencyril”的快捷指令：

1. 接收共享表单输入；没有输入时使用“听写文本”或“询问输入”。
2. 对输入执行“URL 编码”。截图和照片先使用“从图像中提取文本”。
3. 拼接 URL：`obsidian://haidencyril-capture?vault=你的Vault名称&content=编码后的文本`。
4. 使用“打开 URL”。
5. 在快捷指令详情中启用“在共享表单中显示”，也可以添加到主屏幕或操作按钮。

Obsidian 命令“复制苹果快捷指令捕捉地址模板”会复制当前 Vault 的 URL 起点。内容只会写入 Inbox，不会自动调用 AI；若确实需要分析，可在 URL 末尾增加 `&analyze=true`。

## 日历写入快捷指令

默认快捷指令名称是“Haidencyril 日程”，可以在插件设置中修改。建立同名快捷指令：

1. 接收“快捷指令输入”中的文本。
2. 使用“从输入中获取字典”。
3. 分别取得 `title`、`start`、`end`、`notes`。
4. 使用“添加新日程”，把标题、开始日期、结束日期和备注对应填入。
5. 关闭快捷指令自身的“运行时询问”也不会绕过插件确认；插件已经在调用前展示最终时间和课程冲突。

如果设置中的快捷指令名称留空，插件只保存 Markdown 日程账本，不会打开苹果快捷指令。

## 提醒事项写入快捷指令

默认快捷指令名称是“Haidencyril 提醒”，用于不占用日历时间、但需要到点提醒的任务：

1. 接收“快捷指令输入”中的文本。
2. 使用“从输入中获取字典”。
3. 分别取得 `title`、`due`。
4. 将 `due` 交给“从输入中获取日期”；插件传入的是本地时间，例如 `2026-08-10 22:00`。
5. 使用“添加新提醒事项”，标题选 `title`，列表选 `Haidencyril`，先不要设置提醒时间。
6. 紧接着使用“编辑提醒事项”，对象选上一步新建的提醒事项，将“提醒时间”设为第 4 步得到的“日期”。

macOS 快捷指令在“添加新提醒事项”里直接使用动态提醒时间时，可能报“未提供提醒位置”。先创建、再编辑日期可以稳定避开这个系统动作问题。如果仍失败，检查列表是否确实为 `Haidencyril`，以及编辑动作的对象是否连接到刚创建的提醒事项。

固定时间的行动使用日历时间块；只需要截止提醒的事项使用提醒事项。两种写入都必须先在插件中确认日期和时间。

## 日历同步快捷指令

默认快捷指令名称是“Haidencyril 同步日程”。本机已经创建该快捷指令；其他设备可以按下面的结构复制。它读取从现在开始、按开始时间排序的最多 50 项日程，插件只保留未来八天，并把一次只读快照交给当前打开的 Obsidian Vault：

1. 使用“查找日历日程”，筛选开始日期在 0 天以后，按开始日期排序并限制为 50 项。
2. 对每项日程取得标题、开始日期和结束日期；日期使用 ISO 8601 格式。
3. 在循环结束后用“合并文本”把所有结果连成一段文本，再统一执行“URL 编码”。
4. 拼接 URL：`obsidian://haidencyril-calendar-sync?events=编码后的内容`。
5. 使用“打开 URL”。

工作台“日程建议”会显示最近一次同步、课表、临时固定安排与已确认的项目行动。插件不直接申请完整日历权限，也不会静默修改既有事件；只有运行快捷指令时才会产生新的本地快照。

## `.ics` 备用导入

教务系统如能导出 `.ics`，在工作台打开“日程建议”后点击“导入 .ics”。如果只能查看课表，可以先添加到苹果日历，再通过同步快捷指令读取；截图和临时补课通知则先通过 OCR 捕捉为碎片，再从该笔记运行“将当前笔记设为临时固定安排”。插件不会自动登录 `zf.scetop.com`，也不会保存账号或验证码。
