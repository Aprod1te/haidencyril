# 苹果自动化

## 随手捕捉快捷指令

插件注册了 `obsidian://haidencyril-capture`。推荐建立一个名为“记录到 Haidencyril”的快捷指令：

1. 接收共享表单输入；没有输入时使用“听写文本”或“询问输入”。
2. 对输入执行“URL 编码”。截图和照片先使用“从图像中提取文本”。
3. 拼接 URL：`obsidian://haidencyril-capture?vault=你的Vault名称&content=编码后的文本`。
4. 使用“打开 URL”。
5. 在快捷指令详情中启用“在共享表单中显示”，也可以添加到主屏幕或操作按钮。

Obsidian 命令“复制苹果快捷指令捕捉地址模板”会复制当前 Vault 的 URL 起点。内容只会写入 Inbox，不会自动调用 AI；若确实需要分析，可在 URL 末尾增加 `&analyze=true`。

## 日历写入快捷指令

默认快捷指令名称是“Haidencyril 日程”，可以在插件设置中修改。建立同名快捷指令：

1. 接收“快捷指令输入”中的文本。
2. 使用“从输入中获取字典”。
3. 分别取得 `title`、`start`、`end`、`notes`。
4. 使用“添加新日程”，把标题、开始日期、结束日期和备注对应填入。
5. 关闭快捷指令自身的“运行时询问”也不会绕过插件确认；插件已经在调用前展示最终时间和课程冲突。

如果设置中的快捷指令名称留空，插件只保存 Markdown 日程账本，不会打开苹果快捷指令。

## 导入课表

教务系统如能导出 `.ics`，直接点击工作台“导入课表”。如果只能查看课表，可以先添加到苹果日历再导出 iCalendar；截图和临时补课通知则先通过 OCR 捕捉为碎片。插件不会自动登录 `zf.scetop.com`，也不会保存账号或验证码。
