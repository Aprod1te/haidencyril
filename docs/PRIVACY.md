# 隐私说明

## 本地保存的数据

- 原始碎片、分析账本、任务清单与执行记录、项目、苹果日历只读快照、课表导入记录、临时固定安排和日程确认账本保存在用户选择的 Obsidian Vault。
- 插件设置通过 Obsidian `loadData` / `saveData` 保存；笔记之间的关系使用 Markdown 双向链接，不在属性中重复保存文件路径。
- 语义向量保存在插件目录的 `semantic-index.json`，属于可删除、可重建缓存。
- 插件没有遥测、分析统计、广告或自动上传功能。

## 何时会访问网络

插件不会把笔记内容发送到互联网。只有用户主动点击分析、重新分析、语义搜索或整理任务清单时，插件才访问本机的 Ollama 服务；需要生成内容的功能还必须先在设置中启用本地 AI。

每次请求可能包含：

- 用户主动选择的原始碎片全文。
- 用户在分析前主动填写的初步判断和不确定点。
- 由本地关键词重叠筛出的最多 4 条候选笔记摘录，每条最多 600 个字符。
- 候选笔记的 Vault 内路径和文件名，用于创建可点击联系。
- 当前笔记全文，以及用户为任务拆解填写的目标、限制和不确定点。

请求发送到 `127.0.0.1:11434` 的 Ollama 本地接口，并使用 JSON Schema 约束输出。Ollama 下载模型时会访问网络，但分析内容只在本机处理。

语义搜索首次运行或笔记变化时，会将最多 500 篇非分析、非日程 Markdown 的标题和前 6000 个字符发送给本机嵌入模型。向量只保留在插件本地缓存中。

## 不会发送的数据

- 整个 Vault。
- 未被选为候选的笔记内容。
- 教务系统账号或登录会话。

只有用户主动点击同步时，苹果快捷指令才会把未来八天的事件标题、时间和位置写入 Vault 快照。只有用户确认新日程或提醒后，插件才会通过 `shortcuts://` 把标题、确认后的时间和来源说明交给对应的写入快捷指令。

## 多设备注意事项

Vault 可以由用户选择的同步方式同步。iPhone 和 iPad 可以记录、同步、浏览、查看日程建议和调用快捷指令；AI 分析与语义索引只在安装并运行 Ollama 的 Mac 上执行。

## 删除和恢复

原始碎片、分析账本、项目和日程账本都是普通 Markdown 文件，可以使用 Obsidian 的删除和恢复机制处理。禁用或卸载插件不会删除任何笔记；语义索引可以随时删除并自动重建。
