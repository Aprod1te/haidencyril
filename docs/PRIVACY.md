# 隐私说明

## 本地保存的数据

- 原始碎片和分析账本保存在用户选择的 Obsidian Vault。
- 插件设置通过 Obsidian `loadData` / `saveData` 保存。
- OpenAI API Key 由 Obsidian Secret Storage 管理，插件配置只保存密钥名称。
- 插件没有遥测、分析统计、广告或自动上传功能。

## 何时会访问网络

只有同时满足以下条件时才访问 OpenAI：

1. 用户在设置中启用 AI 分析。
2. 用户选择有效 API Key。
3. 用户点击 **保存并分析**、**共同分析**或**重新分析**。

每次请求可能包含：

- 用户主动选择的原始碎片全文。
- 用户在分析前主动填写的初步判断和不确定点。
- 由本地关键词重叠筛出的最多 4 条候选笔记摘录，每条最多 600 个字符。
- 候选笔记的 Vault 内路径和文件名，用于创建可点击联系。

请求使用 OpenAI Responses API，并设置 `store: false`。OpenAI 对 API 数据的处理仍受其当时适用的数据政策约束。

## 不会发送的数据

- 整个 Vault。
- 教务系统账号或密码。
- 未被选为候选的笔记内容。
- 苹果日历、提醒事项或课表；当前版本尚未接入这些数据源。

## 多设备注意事项

Vault 可以由用户选择的同步方式同步。API Key 属于设备和 Vault 的秘密存储；如果新设备上无法读取已有秘密，需要在该设备重新选择或添加密钥。

## 删除和恢复

原始碎片与分析账本都是普通 Markdown 文件，可以使用 Obsidian 的删除和恢复机制处理。禁用或卸载插件不会删除任何笔记。
